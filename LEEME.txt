# ============================================================================
# WOWCHAT MULTI-SESION v1.5.0 - Guia rapida
# Un solo bot de Discord con 3 personajes de WoW (horda / alianza / espanol)
# ============================================================================

## REQUISITOS
  - Java 11, 17 o 21 (el jar es compatible con cualquiera)
  - 512 MB de RAM sobran (el bot consume ~250-280 MB con los flags de abajo)
  - 1 vCPU (consume ~3% de un nucleo con las 3 tabernas activas)

## ANTES DE ARRANCAR (una sola vez)
  1. Copia "wowchat.conf.example" a "wowchat.conf" y completalo:
       - discord.token        -> token de tu bot
       - wow.sessions.*       -> cuenta/clave/personaje de cada sesion
       - chat.channels.*      -> IDs de los canales de Discord
  2. En https://discord.com/developers/applications -> tu app -> Bot:
       - Marca SERVER MEMBERS INTENT
       - Marca MESSAGE CONTENT INTENT
  3. Invita el bot a tu servidor con permisos de: Ver canales, Enviar
     mensajes, Incrustar enlaces y Leer historial de mensajes.

  COMO OBTENER EL ID DE UN CANAL DE DISCORD:
     Ajustes de usuario -> Avanzado -> MODO DESARROLLADOR (activado)
     Click derecho sobre el canal -> "Copiar identificador"

## ARRANCAR
  Linux/Mac:      ./run.sh
  Windows:        run.bat
  Manual:         java -jar wowchat.jar wowchat.conf

## ARRANQUE COMO SERVICIO (Linux + systemd, recomendado para hosting)
  1. sudo nano /etc/systemd/system/wowchat.service
  2. Pega (ajusta usuario y rutas):

       [Unit]
       Description=WoWChat Multi-Sesion
       After=network-online.target

       [Service]
       Type=simple
       User=tuusuario
       WorkingDirectory=/home/tuusuario/wowchat
       ExecStart=/usr/bin/java -Xms64m -Xmx256m -XX:+UseSerialGC -XX:MaxMetaspaceSize=128m -Dfile.encoding=UTF-8 -Dlogback.configurationFile=logback.xml -jar wowchat.jar wowchat.conf
       Restart=on-failure
       RestartSec=15

       [Install]
       WantedBy=multi-user.target

  3. sudo systemctl daemon-reload
     sudo systemctl enable --now wowchat
     Ver logs:   journalctl -u wowchat -f

## NOTAS
  - EMOTES Y FORMATO: se configuran en discord.format_rules del wowchat.conf
    (lista de {pattern, replacement} con regex de Java). Agregar uno nuevo es
    anadir una linea y reiniciar el bot - NO hace falta recompilar nada.
  - El bot escribe logs SOLO a consola. Con systemd los ves con journalctl.
    Si lo corres a mano y quieres persistirlos: ./run.sh >> bot.log 2>&1 &
  - Todas las sesiones deben ser de la MISMA expansion de WoW (version=).
  - Si una sesion falla (clave mala, personaje inexistente), esa sesion se
    detiene y queda marcada "ERROR" en la presencia del bot; las demas
    siguen funcionando. El proceso NO se cae.
  - Los canales de Discord van por ID o por nombre (en minusculas).
  - Los @tags escritos en WoW se convierten en menciones reales de Discord
    si coinciden con el apodo o el nombre de un miembro del canal puente.
